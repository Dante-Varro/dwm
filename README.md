# dwm - Dynamic Window System (Custom Fork)

My personal customized build of `dwm`. 

---

## Patches Included
* **`vanity gaps`** — Adds gaps between client windows. 
* **`systray`** — Adds a system tray.
---

## Installation

Make sure you have Xlib header files installed on your system. 

```sh
git clone https://github.com/Dante-Varro/dwm.git
cd dwm

sudo make clean install
